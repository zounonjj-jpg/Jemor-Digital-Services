# SAVOIR+
Ce dossier contient l'archive de l'application SAVOIR+ indépendante de Jémor Digital House.
Le code est conservé en fragments Base64 dans parts/part*.b64 afin de préserver l'archive sans modifier la racine du dépôt.
Pour un build Vercel depuis ce répertoire : cat parts/*.b64 | base64 -d | tar -xz && npm install ; puis npm run build.
